## Activity Monitor

Activity monitor aims to be an application for people that want to track their habits, activities 
(alone or with someone), so they can rewind and trace the past.

## Core features

As the system is not implemented yet, the verb tense will be future

### Tasks tracking

The application should allow to track different types of tasks, with a convenient set of options to 
match the task type. The types can be:

- Read;
  - Book;
  - Comic;
- Exercise;
  - Gym;
  - Calisthenic;
- Study;
- Work;
- Watching series;
- Cleaning;

### Time monitoring

One of the sub-goals of the system is to have tools for time control. Pomodoro, goals, routine, and
so on.

### Companion

Bring the possibility to add more than one person involved with the activities. Like having dinner
with friends, watching a movie/serie with someone, etc...
